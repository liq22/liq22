## About

I work on trustworthy AI, physics-informed foundation models, and prognostic and health management (PHM) for industrial systems.

My full academic homepage can be found at: [https://liq22.github.io](https://liq22.github.io). It is the source of truth for my publications, news, honors, CV details, projects, and collaborations; this README is intentionally kept as a short profile summary.

## Research Focus

- Trustworthy AI and interpretable diagnosis for industrial equipment.
- Physics-informed and foundation models for PHM.
- Cross-domain diagnosis, domain adaptation, and robust generalization.

## Selected Projects

- [PHMBench](https://github.com/PHMBench): open-source resources and benchmarks for PHM foundation model research.
- [ISFM-HSE](https://github.com/liq22/ISFM_HSE): a plug-and-play module for unified fault diagnosis foundation models.
